# Web UI サイバーパンク化 設計

作成日: 2026-08-08

## 目的

Timothy の管理画面（`GET /`）の見た目を刷新する。現状はシステムフォントと最小限のスタイルで、
機能確認向けの素朴な見た目になっている。

参照するのは Cyberpunk 2077 の UI を題材にしたデザイン
（https://dribbble.com/shots/21534554-Cyberpunk-2077-PPT-Template）。
ほぼ黒の背景に赤の細い線、四隅の L 字ブラケット、シアンの極小モノスペース大文字ラベル、
階段状に折れる 1px の罫線、画面端の細かいデータ列という語彙を持つ。

## 全体方針

デザイントークンを CSS カスタムプロパティとして `:root` に定義し、既存の `hono/css` 定数を
`var(--…)` 参照に置き換える。マークアップの変更は最小限にとどめる。

装飾の強度は「静的な HUD 表現まで」とする。グリッチアニメーション、走査線、ネオングローは
入れない。毎日使う管理画面として長時間見ても疲れないことを優先する。

トークンを介さず各 `css` 定数に色をベタ書きする案も検討したが、赤の階調を 5〜6 種類使うため、
調整のたびに全定数を追うことになるので採らない。コンポーネントを分割して全面再構築する案は、
レイアウト構造（一覧 + フォーム）自体を変えないため過剰。

## フォント

システムにあるフォントのみを使い、外部リソースは読み込まない。

Timothy は自己完結型の自己ホストツールで、管理画面から外部へ出ていく通信は現状ひとつもない。
Google Fonts を読むと閉域環境で崩れ、閲覧者の IP が第三者に渡る。woff2 をリポジトリに置いて
セルフホストする案もあるが、バイナリの追加と配信経路の新設に見合わない。

- 等幅（ラベル・数値・URL）: `ui-monospace, "SF Mono", Menlo, Consolas, monospace`
- 本文・日本語: `system-ui, -apple-system, "Hiragino Sans", "Noto Sans JP", sans-serif`

日本語を等幅にすると可読性が落ちるため混ぜない。サイバーパンクらしさは大文字化と
`letter-spacing: 0.12em` で作る。

## デザイントークン

`:root` に定義する。

| 用途 | 変数 | 値 |
|---|---|---|
| 背景 | `--bg` | `#08090B` |
| パネル地 | `--panel` | `#0E1013` |
| パネル縁 | `--panel-edge` | `#1A1D22` |
| 罫線 | `--line` | `#2A1116` |
| 強い罫線 | `--line-strong` | `#7A1020` |
| アクセント（赤） | `--accent` | `#FF2E3E` |
| メタ情報（シアン） | `--cyan` | `#00E5E8` |
| プライマリ操作（黄） | `--yellow` | `#FCEE0A` |
| 本文 | `--text` | `#D3D7DE` |
| 減光文字 | `--text-dim` | `#7B828E` |

赤を構造線に、シアンをメタ情報のラベルに使う。黄はアップロードボタン 1 箇所のみに割り当てる。
参照デザインは赤とシアンが主で黄はほぼ出てこないが、押すべき場所が一目でわかるようにするため
1 箇所だけ例外を作る。

間隔・線幅・フォントスタックも同じ `:root` にまとめる。

## 各パーツの見え方

**ヘッダー** — `TIMOTHY` を等幅大文字・広めのトラッキングで置き、下に階段状に折れる 1px の罫線。
右端にシアンの極小ステータス行（`FILES: 03`）。

**パネル** — 全周の枠線は引かず、四隅の L 字ブラケットを `::before` / `::after` で描く。
参照デザインの主要なモチーフ。

**アップロードフォーム** — ドロップ領域は破線。通常はシアン系の減光色、ドラッグ中は黄に変わる。
既存の `data-dragging` 属性をそのまま使い、`webScript.ts` は変更しない。
入力欄は下線のみ、フォーカスでシアン。アップロードボタンは黄地に黒文字、右下を `clip-path` で
斜めに落とす。

**一覧** — 縦罫線は引かず横罫線のみ。行頭に `01` `02` の連番を減光した等幅で入れる。
hover でごく薄い赤のウォッシュと左端のアクセントバー。期限切れ行は全体を減光し、赤枠のチップを付ける。

**装飾のデータレール** — 画面左右の端に細かい文字列の縦列を置く。純粋な装飾なので
`aria-hidden="true"` を付け、スクリーンリーダーからは隠す。

**動き** — hover とフォーカスのトランジションのみ。`prefers-reduced-motion: reduce` で無効化する。

## 変更してはいけない文言

既存テストがこれらの文字列で判定しているため、そのまま維持する。

- 期限切れチップ: `期限切れ`
- 空状態: `まだファイルがありません`
- フォームのラベル: `ファイル` / `タイトル` / `説明（任意）` / `有効期間（日）` / `アップロード`
- 削除ボタン: `削除`、コピーボタン: `コピー`
- エラーページ: `一覧を取得できませんでした`

空状態には等幅大文字の `NO FILES` を上に添えるが、日本語の文言は残す。

## 変更してはいけない DOM

`webScript.ts` が ID とデータ属性で要素を引いている。これらは維持する。

`#upload-form` / `#drop-zone`（`data-dragging`）/ `#file-input` / `#title-input` /
`#description-input` / `#ttl-input` / `#submit-button` / `#form-error` /
`[data-delete-id]` / `[data-copy-url]` / `[data-row-error]`

## ファイル構成

```
packages/api/src/routes/
├── web.tsx          # マークアップのみ（Layout / UploadForm / FileTable）
├── webStyles.ts     # 新規: トークン定義と css 定数を集約
├── webScript.ts     # 変更なし
└── web.test.ts      # 既存 23 件を維持し、3 件追加
```

`webStyles.ts` は `hono/css` の `css` タグ付きテンプレートで作った定数を名前付きエクスポートする。
トークンは `:root` に流し込むグローバルスタイルとして `Layout` の `<head>` で `<Style />` と
一緒に出す。

`web.tsx` からは `css` の import が消え、スタイルは変数参照のみになる。
現在 `web.tsx` は 280 行あり、うち約 120 行が `css` 定数。サイバーパンク化でスタイルは倍以上に
膨らむため、`webScript.ts` を分けたのと同じ理由で分離する。

## テスト方針

見た目そのものはテストしない。ブラウザでの目視とスクリーンショットで確認する。

既存の 23 件はすべてマークアップと文言を対象にしているため、それらがそのまま通ることが
リグレッションの主要な担保になる。

追加するのは 3 件。

- `color-scheme: dark` が出力に含まれる
- 装飾のデータレールに `aria-hidden="true"` が付いている
- 行番号（`01`, `02`）が出力に含まれる

コントラスト比は実装時に計算して確認する。本文 `#D3D7DE` / 背景 `#08090B` で約 14:1、
減光文字 `#7B828E` で約 5.4:1、黄ボタンの黒文字で約 16:1 を見込む。いずれも WCAG AA を満たす。
実測が下回った場合はトークンの値を調整する。

## 進め方

ローカルに Firebase エミュレータと API サーバーが動く環境があるため、
実装 → スクリーンショット → 調整のループを回す。仕様を固めすぎず、まず一度組んで
見た目を確認してから細部を詰める。

## スコープ外

- 共有ページ（`/s/:id`）— ユーザーのコンテンツをそのまま配信する場所なので手を入れない
- レスポンシブの作り込み — 一覧テーブルは `overflow-x: auto` で横スクロールさせるに留める
- ライトモード — `color-scheme: dark` で固定する
- CLI の出力配色
- グリッチアニメーション、走査線、ネオングロー
