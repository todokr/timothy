# 一覧のタイトルと説明を 1 カラムに統合

## 背景

Web 管理画面の一覧テーブルは タイトル / 説明 / 共有 / 有効期限 / 作成日時 / 操作 の
6 列あり、1 行が横に長い。

説明はタイトルに従属する情報なので、独立した列を与えずタイトルの下に置く。
横幅を 1 列分詰め、タイトルと説明の関係も見た目に表れる。

他の列（共有・有効期限・作成日時・操作）は現状のまま残す。

## 構造

`<th>説明</th>` と対応する `<td>` を削除し、タイトルのセルを縦積みにする。6 列 → 5 列。

```tsx
<td class={titleCellClass}>
  <span class={titleTextClass}>{file.title}</span>
  {file.description && (
    <span class={descriptionTextClass} title={file.description}>
      {file.description}
    </span>
  )}
</td>
```

説明が空のときは要素ごと出さない。空の `<span>` が残ると `margin-top` の分だけ
行の高さが揺れる。

列見出しは「タイトル」のまま。説明は副次情報であり、見出しに並べると
独立した列に見える。

## スタイル

セルに `max-width: 22rem` を置き、`white-space: normal` で折り返しを許す
（テーブル全体は `nowrap`）。

- **タイトル** … 1 行で `…` 省略（`text-overflow: ellipsis`）。折り返すと行の高さが
  タイトルの長さで変わり、一覧としての走査性が落ちる
- **説明** … `0.75rem` / `--gray-500`、`-webkit-line-clamp: 2` で 2 行まで表示して省略。
  全文は `title` 属性でホバー時に読める

## nth-child の付け替え

`tableClass` は列を位置で指定している。

- `td:nth-child(2)` … 説明（折り返しと最小幅）
- `td:nth-child(4), td:nth-child(5)` … 有効期限と作成日時（`tabular-nums`）

列を 1 つ減らすと後続の番号がずれる。番号を振り直すのではなく、クラス指定に変える
（`titleCellClass` と新設の `dateCellClass`）。位置指定は列構成を触るたびに壊れるので、
今回踏む分だけ直す。

## テスト

- 説明がタイトルと同じセルに描画される（「説明」列見出しが無い）
- 説明が空の行では説明用の要素が出ない
- 既存の一覧テスト（タイトル・共有 URL・無期限表示・期限切れの除外）が通り続ける

## 対象外

- 共有・有効期限・作成日時・操作の各列の見直し
- 日時表示の短縮（時刻を落として日付だけにする等）
- 一覧のレスポンシブ対応
